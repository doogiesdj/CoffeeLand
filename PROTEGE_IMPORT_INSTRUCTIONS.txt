   → Range: xsd:integer

   → Domain: Cooperative
   → Range: xsd:integer

문제 1: "Import ontology" 버튼이 안 보임
해결: Active Ontology 탭에서 "Ontology imports" 섹션의 [+] 사용

문제 2: Import 후 Property가 안 보임
해결: 
  - Data properties 탭 새로고침
  - Reasoner 실행
  - Protégé 재시작

문제 3: "Ontology already imported" 오류
해결:
  - 이미 Import됨 (정상)
  - Data properties 탭에서 확인

문제 4: Domain/Range가 없음
해결:
  - RDF 파일 재확인
  - 수동으로 Domain/Range 추가
