📝 문제 해결
================================================================================

문제: 파일을 열었는데 여전히 개체가 안 보여요
해결:
  1. 올바른 파일을 다운로드했는지 확인
     - 파일 크기: 약 85KB (이전 70KB)
     - 줄 수: 2,451줄
  
  2. Reasoner 실행
     - Reasoner → Start reasoner
  
  3. Individuals 탭 새로고침
     - 탭을 닫았다가 다시 열기
  
  4. 캐시 클리어
     - Protégé 재시작
     - File → Recent files 확인

문제: Classes 탭에 Port/Warehouse가 안 보여요
해결:
  1. Location 클래스를 확장했는지 확인
     - Location 옆의 ▶ 아이콘 클릭
  
  2. Classes 탭 새로고침
     - View → Refresh classes

문제: 속성이 표시되지 않아요
해결:
  1. 개체를 클릭했는지 확인
  2. Properties 탭 확인
  3. Data properties 필터 확인

================================================================================
🎓 배운 교훈
================================================================================

OWL/RDF 온톨로지에서:
  1. Import는 복잡하고 문제가 생기기 쉬움
  2. 클래스와 개체를 같은 파일에 두는 것이 가장 안전
  3. 하나의 통합된 파일이 여러 분리된 파일보다 관리하기 쉬움
  4. Protégé는 메인 온톨로지 파일의 내용을 가장 잘 인식함

모범 사례:
  ✅ 클래스 정의를 메인 파일에 포함
  ✅ 개체를 메인 파일에 직접 삽입
  ✅ Import는 꼭 필요한 경우에만 사용
  ✅ 정기적으로 Reasoner 실행하여 일관성 검증
