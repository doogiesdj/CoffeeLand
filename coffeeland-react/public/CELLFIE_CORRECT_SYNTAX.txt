Types: Farm
Facts:
  hasName @B*,
  hasRegion @C*,
  hasAltitudeRange @E*,
  hasFarmSize @I*,

📝 문법 설명
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Individual: @B*
   → B열의 각 행을 반복하며 Individual 생성
   → Farm_Name 값으로 Individual 이름 생성

2. Types: Farm
   → 모든 Individual을 Farm 클래스로 지정

3. Facts: (속성 정의)
   
   a) Data Properties (리터럴 값):
      hasName @B*                    → Farm 이름 (문자열)
      hasRegion @C*                  → 지역 (문자열)
      hasAltitudeRange @E*           → 고도 범위 (문자열)
      hasFarmSize @I*                → 농장 크기 (문자열)
      hasAnnualProduction @J*(xsd:integer)  → 생산량 (정수)
   
   b) Object Properties (다른 엔티티 참조):
      isLocatedIn @A*(Class)         → Country 클래스 참조
      cultivates @D*(Class)          → CoffeeVariety 클래스 참조
      usesProcessingMethod @F*(Class) → ProcessingMethod 클래스 참조
      memberOf @H*(Class)            → Cooperative 클래스 참조

🎓 Cellfie 문법 핵심 규칙
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 컬럼 참조:
   @A5      → 특정 셀 (A열 5행)
   @B*      → B열의 현재 반복 행
   @*2      → 현재 반복 열의 2행
   @**      → 현재 반복 셀 (행과 열 모두)

2. 타입 지정:
   @A5(Class)              → OWL 클래스로 해석
   @B5(NamedIndividual)    → OWL Individual로 해석
   @C5(xsd:integer)        → 정수 리터럴
   @D5(xsd:float)          → 실수 리터럴
   @E5(xsd:string)         → 문자열 리터럴 (기본값)

3. 이름 인코딩:
   @A5(rdf:ID)             → 셀 값을 직접 ID로 사용
   @A5(rdfs:label)         → 자동 URI 생성 + label로 저장
   @A5(mm:Location)        → 셀 위치 기반 URI 생성 (값 무시)

4. 빈 셀 처리:
   mm:SkipIfEmptyLocation          → 빈 셀이면 전체 표현식 건너뜀
   mm:ProcessIfEmptyLocation       → 빈 셀이면 해당 부분만 건너뜀
   mm:ErrorIfEmptyLocation         → 빈 셀이면 오류 발생
   mm:DefaultLocationValue="..."   → 빈 셀의 기본값 지정

5. 문자열 처리 함수:
   mm:toUpperCase(@A5)             → 대문자 변환
   mm:toLowerCase(@A5)             → 소문자 변환
   mm:prepend("prefix_", @A5)      → 앞에 문자열 추가
   mm:append(@A5, "_suffix")       → 뒤에 문자열 추가
   mm:replace(",", ".", @A5)       → 문자 치환
   mm:replaceAll("[^a-zA-Z0-9]","",@A5) → 정규식 치환

1. 범위 지정 필수:
   - Cellfie GUI에서 반드시 Start/End Row/Column 지정
   - @B* 같은 와일드카드는 이 범위 내에서만 반복

2. 기존 클래스 필요:
   - Farm, Country, CoffeeVariety 등 클래스가 미리 존재해야 함

3. 속성(Property) 필요:
   - hasName, isLocatedIn, cultivates 등 속성이 미리 정의되어야 함
   - 없으면 오류 발생

4. 데이터 타입:
   - 숫자 데이터는 반드시 xsd:integer 또는 xsd:float 지정
   - 문자열은 타입 생략 가능 (기본값)
