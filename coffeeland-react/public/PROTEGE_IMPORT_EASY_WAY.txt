🎯 가장 쉬운 방법 (Active Ontology 탭)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Active Ontology 탭 클릭
  Protégé 상단 탭 영역에서
  "Active Ontology" 탭 찾기
  
  탭 순서: Entities > Classes > Object Properties > Data Properties > Active Ontology

Step 2: Ontology imports 섹션 찾기
  Active Ontology 탭 화면에서
  우측 패널에 "Ontology imports" 섹션 찾기
  
  없다면 좌측 또는 중앙 패널 확인

Step 3: [+] 버튼 클릭
  "Ontology imports" 제목 옆 또는 하단의 [+] 버튼 클릭

Step 4: Import wizard 대화상자
  "Import an ontology" 대화상자가 나타남
  
  선택: "Import an ontology contained in a document"
  [Browse...] 클릭

Step 5: 파일 선택
  coffeeland_data_properties.rdf 선택
  [Open] 클릭

Step 6: Import 방식 선택
  "How do you want to import?"
  
  ⭐ 선택: "Copy ontology to active ontology"
  [OK] 클릭

Step 7: 완료
  Data properties 탭에서 35개 확인

🔧 대안: Loaded ontology sources 창 크기 조정
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

현재 창이 너무 작아서 하단 버튼이 안 보이는 것 같습니다.

Option 1: 창 크기 키우기
  - 창 테두리를 드래그해서 아래로 늘리기
  - 또는 창 최대화

Option 2: 스크롤
  - 창 안쪽을 아래로 스크롤
  - 마우스 휠 사용

하단에 있어야 할 버튼:
  [Import ontology]
  [Remove ontology]
  [Close]

Step 1: Tools 메뉴 클릭
  상단 메뉴바: Tools

Step 2: "Import ontology" 찾기
  Tools 메뉴에서 "Import ontology" 항목 찾기
  (버전에 따라 이름이 다를 수 있음)

Step 3: 파일 선택
  coffeeland_data_properties.rdf 선택

만약 Import가 안 되면, 수동으로 Property 추가:

Step 1: Data properties 탭으로 이동

Step 2: 새 Property 추가
  좌측 상단 [+] 버튼 클릭

Step 3: Property 이름 입력
  예: hasName
  [OK] 클릭

Step 4: Domain 설정
  우측 패널 "Domains (intersection)"
  [+] 버튼 클릭
  → Farm 선택
  → 반복: Country, CoffeeVariety, ProcessingMethod, Cooperative

Step 5: Range 설정
  우측 패널 "Ranges (intersection)"
  [+] 버튼 클릭
  → xsd:string 선택

Step 6: 35개 Property 반복...
  (시간이 오래 걸림 😅)

🚀 가장 추천: RDF 파일 직접 편집

Protégé Import가 어렵다면:

Step 1: coffeeland.rdf 파일 찾기
  G:\내 드라이브\ProtegeWorkspace\coffeeland.rdf

Step 2: 텍스트 에디터로 열기
  메모장, VS Code, Notepad++ 등

Step 3: </rdf:RDF> 태그 찾기
  파일 맨 끝에 있음

Step 4: </rdf:RDF> 바로 위에 내용 추가
  coffeeland_data_properties.rdf 내용 복사
  
  주의: <?xml version="1.0"?> 태그는 복사 안 함!
  주의: 맨 위/맨 아래 <rdf:RDF> 태그도 복사 안 함!

Step 5: 저장
  coffeeland.rdf 저장

Step 6: Protégé에서 Reload
  File > Reload (Ctrl+Shift+R)
