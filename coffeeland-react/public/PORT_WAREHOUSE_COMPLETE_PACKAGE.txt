================================================================================
🐛 TROUBLESHOOTING
================================================================================

Issue: "Port or Warehouse class not found"
Solution:
  1. Go to Classes tab in Protégé
  2. Right-click "Location" class
  3. Add subclass → "Port"
  4. Add subclass → "Warehouse"
  5. Save and retry import

Issue: "Data properties not recognized"
Solution:
  1. Go to Data Properties tab
  2. Create missing properties (see list above)
  3. Set domain: Port or Warehouse
  4. Set range: xsd:string, xsd:integer, or xsd:double
  5. Retry import

Issue: "Coordinates not displaying correctly"
Solution:
  • Ensure hasLatitude and hasLongitude are xsd:double type
  • Use decimal notation (period, not comma)
  • Check for typos in CSV data

Issue: "Python script fails"
Solution:
  • Verify Python 3 is installed
  • Check CSV files are in same directory as script
  • Ensure CSV headers exactly match script expectations
