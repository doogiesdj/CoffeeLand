=================================================================
🚀 METHOD 1: PROTÉGÉ GUI IMPORT (RECOMMENDED)
=================================================================

Step 1: Prepare Protégé
  1. Launch Protégé application
  2. File → Open → Select coffeeland.rdf
  3. Wait for ontology to load fully

Step 2: Verify Classes Exist
  1. Go to "Classes" tab
  2. Verify "Location" class exists
  3. Verify "Port" and "Warehouse" are subclasses of Location
     (If not, create them first:
      - Right-click "Location" → Add subclass → "Port"
      - Right-click "Location" → Add subclass → "Warehouse")

Step 3: Import Individuals
  1. File → Merge with Imported Ontology...
  2. Browse and select: coffee_logistics_individuals.rdf
  3. Click "OK" to import
  4. Wait for import to complete

Step 4: Verify Import
  1. Go to "Individuals" tab
  2. Select "Port" class → Should show 15 individuals
  3. Select "Warehouse" class → Should show 20 individuals
  4. Click any individual to view properties

Step 5: Save
  1. File → Save (Ctrl+S / Cmd+S)
  2. Confirm save location

=================================================================
🔧 METHOD 2: CELLFIE PLUGIN (ALTERNATIVE)
=================================================================

Step 1: Install Cellfie Plugin
  1. Protégé → File → Check for plugins
  2. Install "Cellfie" plugin
  3. Restart Protégé

Step 2: Prepare CSV Files
  • Use coffee_ports_data.csv
  • Use coffee_warehouses_data.csv

Step 3: Import via Cellfie
  1. Tools → Create axioms from Excel/CSV workbook
  2. Load CSV file
  3. Define mapping rules:
     - Class Expression: Port (or Warehouse)
     - Individual column: PortID (or WarehouseID)
     - Map each CSV column to data property
  4. Generate axioms
  5. Save ontology

Note: Cellfie method requires manual mapping configuration
Recommended to use Method 1 (GUI Import) for simplicity

  • Follow Method 1 instructions above

❓ TROUBLESHOOTING
=================================================================

Issue: "Cannot find Port/Warehouse classes"
Solution: Create classes first in Protégé Classes tab
  - Add "Port" as subclass of "Location"
  - Add "Warehouse" as subclass of "Location"

Issue: "Data properties not recognized"
Solution: Ensure data properties exist in ontology
  - Go to Data Properties tab
  - Create missing properties if needed
  - Set correct domain and range

Issue: "Import shows 0 individuals"
Solution: Check RDF file format
  - Verify XML is well-formed
  - Check namespace matches ontology
  - Re-run Python converter

Issue: "Coordinates not displaying"
Solution: Verify datatype
  - hasLatitude and hasLongitude should be xsd:double
  - Check decimal format (use period, not comma)

Issue: "Python script fails"
Solution: 
  - Ensure Python 3 is installed
  - Check CSV files are in same directory
  - Verify CSV headers match script expectations
