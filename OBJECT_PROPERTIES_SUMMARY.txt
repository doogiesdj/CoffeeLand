방법 1: Active Ontology 탭 (추천!)
────────────────────────────────────────────────────────────────

1. Protégé > Active Ontology 탭 클릭

2. 우측 패널 "Ontology imports" 섹션

3. [+] 버튼 클릭

4. "Import an ontology contained in a document" 선택
   → [Browse...] 클릭
   → coffeeland_object_properties.rdf 선택

5. "Copy ontology to active ontology" 선택

6. [OK] 클릭

7. Object properties 탭에서 9개 확인


방법 2: RDF 파일 직접 편집 (가장 확실!)
────────────────────────────────────────────────────────────────

1. 파일 다운로드:
   coffeeland_object_properties_MERGE_ONLY.rdf

2. coffeeland.rdf 텍스트 에디터로 열기

3. 파일 맨 끝 </rdf:RDF> 태그 찾기

4. </rdf:RDF> 바로 위에 내용 붙여넣기:
   
   ... (기존 Data Properties) ...
   
   <!-- CoffeeLand Ontology Object Properties -->
   <!-- Generated: 2025-12-29 -->
   
   (여기에 coffeeland_object_properties_MERGE_ONLY.rdf 내용 붙여넣기)
   
   </rdf:RDF>

5. 저장 (Ctrl+S)

6. Protégé > File > Reload (Ctrl+Shift+R)

7. Object properties 탭에서 9개 확인
