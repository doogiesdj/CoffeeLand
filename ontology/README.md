# 온톨로지 파일 디렉토리

이 디렉토리는 Protege에서 export한 CoffeeLand RDF/OWL 파일을 저장하는 곳입니다.

## 사용 방법

1. Protege에서 coffeeland 온톨로지를 다음 형식으로 export:
   - RDF/XML (`.owl` 또는 `.rdf`)
   - Turtle (`.ttl`)
   - N-Triples (`.nt`)
   - N3 (`.n3`)

2. Export한 파일을 이 디렉토리에 저장 (선택사항)

3. 웹 애플리케이션에서 파일 업로드를 통해 사용

## 참고

- 이 디렉토리의 파일은 Git에 커밋되지 않습니다 (`.gitignore` 설정)
- 실제 운영 환경에서는 웹 인터페이스를 통해 업로드하세요
- 샘플 또는 테스트용 온톨로지 파일을 여기에 보관할 수 있습니다
