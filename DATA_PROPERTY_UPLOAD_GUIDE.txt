🎯 방법 1: Protégé GUI에서 수동 추가 (추천 - 학습용)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1: Data Properties 탭 열기
  Protégé 상단 탭: Entities > Data properties

Step 2: 새 Data Property 추가
  좌측 상단: [+] 버튼 클릭
  → "Create new property" 대화상자

Step 3: Property 이름 입력
  예: hasName
  → OK 클릭

Step 4: Domain 설정 (어떤 클래스가 이 속성을 가지는가?)
  우측 패널: "Domains (intersection)"
  [+] 클릭 → Farm 선택

Step 5: Range 설정 (속성 값의 데이터 타입)
  우측 패널: "Ranges (intersection)"
  [+] 클릭 → xsd:string 선택
  
  데이터 타입 옵션:
    xsd:string    → 문자열 (기본값)
    xsd:integer   → 정수
    xsd:float     → 실수
    xsd:boolean   → 참/거짓
    xsd:date      → 날짜
    xsd:dateTime  → 날짜+시간

Step 6: (선택) Annotations 추가
  우측 패널: "Annotations"
  [+] 클릭 → rdfs:label → "Farm Name"
  [+] 클릭 → rdfs:comment → "The name of the farm"

⚠️ 주의사항
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Property 이름 규칙:
   - camelCase 사용 (hasName, not has_name)
   - 명확한 이름 (hasName vs name)
   - 일관된 접두사 (has, is, etc.)

2. Domain/Range 필수:
   - Domain: 어떤 클래스가 이 속성을 가지는가?
   - Range: 속성 값의 데이터 타입은?
   - 없으면 Reasoner 오류 가능

3. 데이터 타입 선택:
   - 숫자는 xsd:integer 또는 xsd:float
   - 텍스트는 xsd:string
   - 참/거짓은 xsd:boolean
   - 날짜는 xsd:date 또는 xsd:dateTime

4. 중복 방지:
   - 같은 이름의 Property가 이미 있는지 확인
   - Protégé는 중복 허용하지만 혼란 야기
